# 🎪 Vienna Free Events

Browse free events in Vienna — concerts, film screenings, dance, theater, sport and more.

**Live site:** https://vienna-free-events.netlify.app

## Features

- 🎪 Browse free events in Vienna from May to September
- 🗂 Filter by category (music, film, dance, theater, sport, literature, festival)
- 📅 Filter by date range
- 🔍 Search by keyword
- 🌐 Bilingual: English & German with one-click toggle
- 📱 Fully responsive

## Tech Stack

- **Frontend:** Angular 17, Tailwind CSS
- **Backend:** Node.js, Express — [vienna-events-api](https://github.com/bvillei/vienna-events-api)
- **Database:** PostgreSQL (Supabase)
- **Hosting:** Netlify (frontend) + Render (backend)

## Local Development

```bash
npm install
npm start
```

Open http://localhost:4200 — make sure the backend is also running locally.
